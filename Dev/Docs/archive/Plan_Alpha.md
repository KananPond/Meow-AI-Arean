## 历史价值

本文是 Desert Arena 的第一版方向稿，确立了以下长期目标：

- 本地 AI 算法与叙事双轨社区赛。
- 红蓝无头对抗，选手提交代码，引擎自动评测。
- 引擎与选手链路最终使用 Go 标准库。
- 进程隔离、换边重启、严格时间预算。
- 胜负标签与多维计分分离。
- 赛后叙事榜独立于算法名次。

这些方向仍有效，但具体设计已由 `Plan_Beta.md` v1.0 重新拍板。

## 已被取代的具体决策

| 历史设想 | 当前基线 |
|---|---|
| 10 TPS、1200 tick | 20 TPS、600 tick |
| 60ms 死线 | 120ms 决策预算，同时保留进程级 deadline/kill |
| 连续或累计 5 次红牌 | v1.0 默认连续 3 次故障出局 |
| 兵力随 seed 随机 | 固定 500 CU、母舰 + 2 LAV |
| 泰勒展开硬编码弹道 | RK4 二次阻力 + 重力外弹道 |
| 512² 初始正式地图 | v1.0 固定 256²，512² 延后 |
| Python 外层调度 | 正式链路由 Go 组织；赛制脚本层后续再定 |
| Prompt 警告限制 Goroutine | 提交时 AST import 白名单 + 进程隔离 |
