## 5. 命令状态机（MVP 内部定义，非原作）

```
idle ──右键地面──▶ move(path[]) ──到达──▶ idle
  │                    │
  │                    └─遇到敌人(attackMove)─▶ engage ─敌人消失─▶ 继续 path
  ├─右键敌人──▶ attackTarget ──目标死亡──▶ idle
  ├─`A`+点地──▶ attackMove ──到达──▶ idle
  ├─`S`──────▶ idle（清空 path 与 target）
  ├─`G`+目标─▶ guard（围绕目标，追击后返回）
  └─Salvager─▶ harvest 循环（母舰 ↔ 资源点）
```

每个单位保存 `state / path[] / target / waypoints[] / cooldown`。逻辑以固定 tick 推进，渲染插值。

## 6. 明确不做的事（与原作的差异，须写进 MVP README）

1. **不做 3D 镜头旋转与俯角**：MVP 是 2D 俯视 Canvas，用缩放代替镜头推拉。
2. **不做阵营不对称**：双方单位与数值完全一致，服务 Mirror Match。
3. **不做空中单位、防空、科技树、veterancy、沙尘暴、昼夜、战役剧情**。
4. **不做「拾取并交付 artifact」**：本项目是持续占点计分的 VP 点。
5. **不做传感器「知有单位不知构成」**：迷雾内敌方完全不可见。
6. **不做原作按键不可重绑定的限制**：MVP 键位固定但允许后续改配置。
7. **不使用原作美术、名称作品牌**：单位类型为功能性通称。

## 7. 验收清单（怎么算「操作像」）

- [ ] 能框选一群单位，右键让它们走，Shift 排出折线路径
- [ ] `A` 攻击移动时，部队会打沿途敌人而不是直冲终点
- [ ] 把 Railgun 放在沙丘后，火力线变虚线且打不中；把 Artillery 放同一位置仍能开火
- [ ] 站在高地的单位对低地目标有 `+` 标记且伤害更高
- [ ] 右键悬停时能看到目标点的蓝/橙优劣提示
- [ ] `Space` 能切到全图等高线战术视图
- [ ] 母舰能缓慢移动，但遇到陡坡会停下 / 绕路
- [ ] 采集车在资源点与母舰之间往返，被击杀会中断收入
- [ ] 摧毁敌方母舰立即结束；时间到则按 VP → KD 差 → 母舰 HP 判定
- [ ] 结算显示八领域加权总分，且「惨胜」的总分可能低于「惜败」
