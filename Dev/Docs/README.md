## 引用规范

正文里用 `[Sxx]` 标注来源编号，例如：

> 高地单位对低地单位有伤害加成 `[S07][S13]`，视线被沙丘阻挡时火力线显示为虚线 `[S02][S09]`。

`[Sxx]` 一律对应 [ATTRIBUTION.md](ATTRIBUTION.md) 中的条目。凡没有编号的句子，要么是本项目自己的设计判断，要么显式标注「推测 / 建议」。

## 与项目的关系

- `Plan_Beta.md` v1.0 中引用原作机制的设定，应能回溯到本目录的事实卡片；明确偏离原作的规则以 v1.0 决策台账为准。
- 需要回溯「当时为什么这么定」时看 [`archive/`](archive/)，但**不要**用归档里的数值做实现依据。
- `Dev/MVP/` 是冻结 JS 预言机，不属于本资料库，也不是正式运行时代码。
- 正式赛执行链在 `war_of_desert/`（`cmd/arena`、`internal/*`、`engine/*`）；可运行的 JS 规则参考实现只在冻结 `Dev/MVP/` 中。
