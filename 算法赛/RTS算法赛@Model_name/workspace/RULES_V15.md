生产、单位表、科技树基础仍然有效；**与本文冲突的地方以本文为准**。

- 单局 **1500 tick**（20 tick/s，75 秒）；每拍 120 ms 决策预算，连续 3 次红牌判负。
- 开局 `hello` 里 `ruleset` 仍为 `"v15"`（实验通道），但 `rulesHash` 是 v1.9.1 指纹；
  本地对局和评测必须是同一个指纹。`protoVersion` 仍是 5。

  两侧同拍同序生产的单位落点互为镜像。
- v1.7.2 移除「遗产科技等级」「唯一送达件数」两条 tie-break：共享遗产供给下它们
  与先手高度相关，会把几拍经济差放大成 57:43 的决胜偏置。
- v1.8.0 把人口上限从 24 提到 **36**（v1.4 仍为 24），并让全部参考 Bot 压向敌方 VP。
- v1.8.1 下调远程攻坚兵造价：**RAILGUN 240 CU / 40 RU**、**ARTILLERY 550 CU / 180 RU**（v1.4 保持原价），
  让「射程压过母舰」的拆舰路线在一局内可负担。
- v1.8.2 给 RAILGUN / ARTILLERY 对母舰的伤害 **×1.5**，缩短拆舰所需输出时间。
- v1.8.3 修正「高差据守」：neutral 模式只在敌人进入自身射程时才因高差原地不动。
  之前只要最近敌人低 1 级就停住，哪怕它在半张图外，部队会永久卡在半路。
- v1.9.0：遗产科技 R1–R4 研究时间缩短为 **60/85/110/135 tick**；研究舰 **100 CU / 25 tick / 速度 5.0**；
  RAILGUN 速度 2.0 格/s、ARTILLERY **550 CU / 180 RU / 75 tick / 速度 1.8 格/s**；
  新增参考 Bot **Warden**（RAILGUN + ARTILLERY + CARRIER 攻城编成）。
- v1.9.1：遗产补给从每 100 tick 提到 **70 tick**，场上无主遗产上限 2 → **3**，
  让遗产科技在缩短后的对局里有更多机会铺开。

## 1. 胜利分（VS）

`tick.vs` 为 `{kills, relics, flags, total, delivered, stored}`；`total` 恒等于前三项之和。

| 来源 | 分值 |
|---|---:|
| 第 1/2 件遗产入库 | 每件 **+50**，每方上限 **100** |
| 第 3 件起遗产入库 | **0 胜利分**，只推进遗产科技 |
| 插旗 | **0** |
| 被拔旗（守方） | **−25**，每次失去 VP 都扣 |
| 拔旗（攻方） | **+25**，同一 VP 每方只结算一次 |
| 击杀 | `min(造价 × 2 ÷ 3, 200)`；母舰 300 |
| 阈值 | **300**；时间到按 VS → KD 差 → 母舰 HP% → 旗控制（领先 >5% 才判） → 平 |

**库存遗产分会被撤回**：旗被击毁时，该 VP 上已发过分的遗产逐件扣回 50，然后守方再扣 25；
遗产掉回地面，攻方可以捡走重新入库，拿自己的 50 分和科技。

## 2. 新单位：研究舰（RESEARCH）

| 属性 | 值 |
|---|---|
| HP / 装甲 | 80 / light（脆皮） |
| 速度 / 视野 | 5.0 / 9 |
| 攻击 | 无 |
| 造价 / 建造 / 人口 | 100 CU / 25 tick / 2 |
| 击杀分 | 66 |

研究舰只能做一件事：**停在己方旗附近（约 2.5 个 VP 半径），研究遗产科技**。

- 该 VP 必须有己方旗，并且库存遗产数量达到节点要求。
- 研究舰离开 VP 圈：研究**暂停**，进度保留。
- 研究舰被击毁：当前研究**取消**，进度和已投入 CU 损失；库存遗产保留，可造新舰从 0 开始。
- 旗被拔：当前研究**取消**，进度和 CU 损失；库存遗产掉地并撤回已发胜利分，再扣 −25。
- 已完成的研究节点**永久保留**；之后旗再被拔，只撤遗产胜利分和过载。

## 3. 遗产科技树

科技从**第 2 件库存遗产**开始，第 1 件只给 50 分。

| 节点 | 该旗库存要求 | 研究 | 效果 |
|---|---|---:|---|
| R1 遗产电池 | 2 件 | 60 tick / 0 CU | 战斗单位伤害 +10% |
| R2 磁轨超导 | 3 件 | 85 tick / 0 CU | 炮塔转速 +15%，CEP −10% |
| R3 复合遗产装甲 | 4 件 | 110 tick / 0 CU | HP +10%，受到伤害 −10% |
| R4 遗产核心 | 5 件 | 135 tick / 0 CU | RAILGUN/ARTILLERY 射程 +1 格，伤害 +15% |
| 过载 | 6 件以上 | 被动 | 每多 1 件库存 +2% 伤害，最多 +20%；旗毁即失去 |

遗产科技**不能**通过普通 `research` 动作研究；必须由研究舰在旗下自动推进。

## 4. 遗产运输与插旗

- 4 个镜像遗迹点，位于地图中心 ±10% / ±6%；开局 2 件，每 70 tick 补 1 件，场上最多 3 件无主。
- 采矿机发 `{"type":"relic","id":12,"relicId":3}` 后自动：寻路 → 装载 30 tick → 送往最近己方旗 → 入库 30 tick。
- 负重移速 ×0.8。
- 入库时若 VP 圈内有**敌方战斗单位**（LAV/AAV/RAILGUN/ARTILLERY/CARRIER），读条暂停。
- 插旗仍是采矿机在无旗 VP 圈内**静止** 30 tick 自动完成；插旗 0 分。
- 旗 HP 160，任何单位可 `attackFlag`；旗毁后库存遗产全部掉地。

## 5. 射击、火控与等级

与 v1.5 相同：`facing`/`turret`、射界、CEP、全局直伤 ×1.8、火控 C1–C3、五级军衔。
遗产科技 R1–R4 是额外的战斗加成。

## 6. 计分卡

七领域：**胜利分 / 歼敌 / 保存兵力 / 母舰完整度 / KD 差 / 旗控制 / 遗产吞吐**。
权重 `[0.25, 0.25, 0.10, 0.10, 0.05, 0.10, 0.15]`。
字段 7 用**唯一送达件数**，所以第 3 件以上遗产虽然 0 VS，仍会提高遗产吞吐分和科技。

## 7. 协议新增

- `tick.vs`：`delivered`（唯一送达件数）、`stored`（当前库存件数）。
- `tick.flags[]`：`stored`（该 VP 库存件数）。
- `tick.me.research`：`{node, vp, ship, progress, total, active, paused}`。
- 事件：`research-start` / `research-done` / `research-cancel` / `flag-bounty` / `relic-blocked`。
