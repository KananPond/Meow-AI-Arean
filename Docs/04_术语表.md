## 六、本项目自造术语（非原作）

| 词 | 含义 |
|---|---|
| VP 点 | Victory Point，本项目自定的持续占点计分目标，**不是** DoK 的 artifact |
| 加权总分 / `match_score` | 本项目自定的多领域单局计分卡结果，与单局胜负标签相互独立 |
| `base` 层 / `elev` 层 | 本项目地图的双层数据结构：地表类型 + 连续高度场 |
| 直射 / 曲射 | 本项目对「受视线约束的即时射击」与「可越障但有飞行时间与散布的抛物线射击」的区分 |
| 判定链 | 本项目五级胜负兜底顺序（斩舰 → VP → KD 差 → 母舰 HP → 平局） |
