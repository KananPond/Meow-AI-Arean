## 0. 摘要：为什么要调研这款游戏

本项目的 `Plan_Alpha.md` 写明「游戏模仿家园卡拉克沙漠」，`Plan_Beta.md` 把玩法定为「二维底图 + 算法生成的等高线层，等高线作为移动与开火的修正依据」，并设置了「VP 点 + 防御母舰 + 斩舰即胜」的胜负结构。要做一个「实现类似卡拉克沙漠的游戏操作」的 MVP，必须先回答三个问题：

1. 原作里**哪些操作是标志性的**（不只是通用 RTS 框选/右键）？
2. 「地形影响战斗」在原作中**具体通过哪几条规则生效**？
3. 母舰、资源、胜利条件之间是什么关系，MVP 该保留哪一层？

调研结论一句话：**卡拉克沙漠把《家园》太空的 Z 轴翻译成了「沙丘高度」**，于是「高度」同时承担了射程、伤害、精度、视线、寻路五件事，并用一套极简的可视化（等高线战术地图 + 蓝/橙地形圈 + 实线/虚线火力线）把这套复杂信息交给玩家 `[S02][S05][S07]`。这正是本项目「等高线作为移动与开火修正依据」的原型，也决定了 MVP 的操作重点不是「造多少兵」，而是**在哪里打、从哪条线打**。

## 2. 核心玩法循环

原作的基本循环与常规 RTS 不同，属于**「移动基地式战术 RTS」**：

```
母舰（可缓慢移动的基地）
   ├─ 生产单位 / 研究科技 / 接收资源
   ├─ 能量在四个子系统间动态分配
   └─ 自身也是强力战斗单位
采集单位 → 从地图上的资源 pockets 采集 → 运回母舰或支援巡洋舰
   → CU / RU 两种资源 → 造兵 / 升科技
部队 → 争夺高地、视线与资源点 → 交战 → 单位与资源跨关继承（战役）
胜利 → 摧毁敌方母舰 或 收集并交付指定数量 artifacts
```

要点：

- **没有固定基地建筑布局**：所有产能、科研、资源卸货集中在母舰，玩家不必摆建筑、不必守一片固定阵地 `[S11][S14]`。
- **资源是「线」不是「点」**：采集车要从母舰出发到资源点、装载、再运回；母舰与资源点的距离直接决定采集效率，因此「把母舰往资源点靠」本身就是核心决策 `[S11]`（中文攻略也有同类描述，见 `[S19]`）。
- **持久舰队**：战役中存活单位带到下一关，损失会在后续关卡持续产生代价；单位 veterancy 让「保住老兵」比「换战损」更重要 `[S01][S11][S14][S15]`。
- **节奏偏慢**：有评测明确指出 Rush 在这款游戏里基本不可行，部队移动慢、生产慢，一场战役关卡可能耗时很久 `[S19]`。这对本项目是重要提醒：**如果我们的 MVP 让「直冲母舰」成为最优解，就丢掉了原作最核心的节奏感**。

## 3. 地形系统（本报告最重要的一节）

### 3.1 地形有三层含义，不只是「好看」

多来源交叉后可归纳为**五条同时生效的规则**：

| # | 规则 | 具体表现 | 来源 |
|---:|---|---|---|
| T1 | **视线约束** | 单位必须能「看到」目标才能准确射击；高地或特殊技能可遮挡视线 | `[S05][S12][S14]` |
| T2 | **高地加成** | 位于更高处的单位攻击低处目标时，获得伤害 / 精度 / 射程方面的优势；血条旁显示「+」图标 | `[S05][S07][S13][S14][S15]` |
| T3 | **地形限制通行** | 大型单位（尤其母舰）会被较缓和的地形挡住，必须绕平缓路线；轻型单位几乎可翻越所有地形；空中单位完全不受影响 | `[S05][S12][S19]` |
| T4 | **反斜面隐蔽** | 沙丘背面可集结部队而不被看见；传感器可能探知「那里有东西」但不知道具体构成 | `[S13][S14]` |
| T5 | ** chokepoint** | 沙丘如山、峡谷把地图切成迷宫，形成天然咽喉点 | `[S02]` |

社区 Wiki 把地形对战斗的影响明确归纳为三条（视线、遮挡、高地加成），并单独指出大型单位的通行限制 `[S05]`；媒体评测补充了伤害/精度/射程加成与反斜面伏击 `[S13][S14][S15]`。

> **关于「三级地形」**：GamingTrend 评测提到地图可辨识三级地形 `[S15]`。本项目 `Plan_Beta.md` 建议存**连续高度场**、等高线只作渲染层——这与「三级」并不冲突：三级是玩家可感知的战术分层，连续值是底层计算所需。MVP 会用连续高度 + 等高线渲染 + 三档颜色提示来同时满足两者。

### 3.2 等高线如何传达给玩家

这是原作最值得抄的 UI 设计，有三套互补的可视化：

1. **战术地图 / 传感器视图**：用**等高线**区分地形高低，一眼看出哪里高哪里低 `[S07]`。传感器视图中单位以形状区分：小型单位三角形、中型方形等 `[S07]`；另有中文攻略描述蓝方块=己方母舰、红点=敌方、白点=友方 `[S09]`。
2. **下令时的 360° 距离圈**：选中单位后脚下出现圆环，光标越远圆环越大，环上会显示等高线；**蓝色表示把单位移到那里有地形优势，橙色表示劣势** `[S02]`。这是把「高度差」即时翻译成「该不该走这一步」的最优雅做法。
3. **火力线**：攻击移动/指向目标时，从每个攻击单位画出红色连线，**实线=直射通畅，虚线或断线=被遮挡** `[S02][S09][S12][S19]`。玩家据此判断该绕行、抢占高地，还是改用曲射单位。

另外，下令时会显示地形「蓝图」标出高低 `[S12]`；沙丘两侧即使距离很近，直线弹道也打不中对方 `[S10]`。

### 3.3 弹道：直射 vs 曲射

- 原作回归初代的**真实物理弹道判定**：射没射中看最终撞击点，而不是「子弹发出即判定命中」的数据判定 `[S10]`。快速廉价的小车有时能靠走位让笨重炮塔跟不上，从而无伤单挑远程单位 `[S10]`。
- **直射**（如 Railgun）受地形遮挡影响极大：沙丘能挡住 railgun `[S15]`，被挡时火力线断开 `[S09]`。
- **曲射**（Artillery Cruiser）把弹丸向上打出，**可以从高地或障碍物后方开火**，代价是弹丸有飞行时间、可能打空、可能误伤己方 `[S04]`。这是「用曲射破解反斜面」的战术来源。
- 烟幕（AAV / Battlecruiser 技能）会**同时阻断敌我视线**，可用于撤退或逼近远程单位 `[S04]`。

### 3.4 对本项目的直接结论

`Plan_Beta.md` 已提出「直射怕反斜面、曲射怕精度」的设计，本调研**完全支持**这一判断，并补充两条：

- 原作把**移动指令与地形信息合并可视化**（蓝/橙圈）——MVP 应该实现一个简化版：右键悬停时显示目标点的高度优势提示。
- 原作母舰「只能走平缓地形、需要绕路」是真实机制 `[S05][S12]`，MVP 若实现可移动母舰，必须让它受坡度约束，否则丢掉一个标志性特征。

## 4. 母舰系统

母舰（Coalition 的 **Kapisi**，Sakala 级指挥母舰 `[S23]`）在原作里同时是六种角色：

| 角色 | 说明 | 来源 |
|---|---|---|
| 生产基地 | 所有单位生产集中于此 | `[S01][S11]` |
| 科研中心 | 单位类型解锁与升级都在母舰研究 | `[S01][S11]` |
| 资源卸货点 | 采集车把资源运回母舰（或支援巡洋舰做远端卸货） | `[S04][S11]` |
| 移动基地 | 可缓慢移动；体积大，受地形限制需绕路 | `[S03][S05][S08][S12]` |
| 空中平台 | 可派出战斗机 / 轰炸机 / 炮艇，出击后返回补给、有冷却 | `[S04][S13][S14]` |
| 强力战力 | 自带机炮、导弹、战术导弹；升级后可单枪匹马改变战局 | `[S01][S14][S19]` |

**四子系统能量分配**是最有辨识度的机制：能量可在 **装甲（Armour）/ 自修复（Repair）/ 攻击（Attack Power / Weapons）/ 射程（Range / 武器与传感器射程）** 之间动态调度 `[S09][S11][S14]`。投入越多效果越强，但会产生**过热风险**，只适合临时应急 `[S13][S14]`。教程关第一步就是让玩家把能量切到防御系统 `[S03]`。

> 本项目 `Plan_Beta.md` 的「防御母舰」原型就是它。MVP 建议保留：可移动（缓慢）、可生产、**四子系统能量条**、被摧毁即判负；砍掉空中单位与战术导弹。

## 5. 单位体系

### 5.1 三元克制（Rock-Paper-Scissors）

教程与单位图鉴给出一致的三角关系 `[S03][S04][S14]`：

```
轻型 (LAV / Sandskimmer)  ──克──▶  远程 (Railgun)
      ▲                                  │
      │                                  │克
      │克                                ▼
装甲 (AAV / Assault Ship) ◀──────────────┘
```

教程里的原话逻辑是「轻单位打远程、装甲单位打轻单位、远程单位（railgun）打装甲单位」`[S03]`。另有地面/空中之间的第二组克制（战斗机克远程与火炮、防空车克所有飞机、轰炸机克地面集群、炮艇克轻单位但自身脆弱）`[S04]`。

### 5.2 单位职能表（Coalition 为主）

| 单位 | 职能 | 标志性技能 / 特征 | 来源 |
|---|---|---|---|
| Salvager | 资源采集与运输 | 一个资源点最多同时由 2 台采集；可用爆破打开残骸 | `[S04][S05]` |
| Support Cruiser | 维修、远程炮塔、兼资源卸货点 | 昂贵；升级后可防空 | `[S04]` |
| Baserunner | 侦察 / 部署炮塔与探针 | 多人模式用它拾取 artifact | `[S04][S16]` |
| LAV | 轻型高速突击 | Boost（约 +60% 速度、10 秒）、只耗 CU | `[S04][S06]` |
| AAV | 装甲突击 | 烟幕（约 10 秒，双向阻断视线）、压制减速 | `[S04]` |
| Railgun | 远程直射高伤 | 射速慢、移动中不准、被动「Sunder」削甲 | `[S04]` |
| Missile Battery | 防空 / 迫击 AoE | 无对地常规武器 | `[S04]` |
| Battlecruiser | 最重地面单位 | 血量约为母舰一半、烟幕 | `[S04]` |
| Artillery Cruiser | 超远程曲射 | **越障射击**、弹丸飞行时间、易误伤、近身弱 | `[S04]` |
| Assault Cruiser | 中庸突击巡洋舰 | Overcharge / 自修 / 战术导弹 | `[S04]` |
| Strike Fighter / Bomber / Gunship | 空中打击 | 从母舰出击→返回补给→冷却 | `[S04][S13]` |

### 5.3 数值量级（社区整理，非官方）

Steam 社区指南给出过一份单位数值表 `[S06]`，可用于校验 MVP 的**相对量级**而非绝对值：

| 单位 | CU | RU | Speed | Hull | Damage |
|---|---:|---:|---:|---:|---:|
| LAV | 100 | 0 | 110 | 500 | 15 |
| AAV | 180 | 30 | 80 | 1400 | 10 |
| Railgun | 200 | 60 | 75 | 675 | 285 |
| Salvager | 100 | 0 | 75 | 900 | 0 |
| Battlecruiser | 800 | 225 | 50 | 6500 | 300 |
| Artillery Cruiser | 450 | 250 | 50 | 2500 | 250 |

规律很清楚：**速度快的皮薄、伤害高的皮薄射速慢、重甲慢且贵**。MVP 的数值表会照这个比例缩放，但会明确标注「本项目自定义，非原作数值」。

### 5.4 其他单位机制

- **Veterancy**：存活够久的单位升级，获得射程、视野、装甲、生命、射速、伤害等加成 `[S05][S14][S15][S23]`。
- **无队形**：本作移除了前作的编队阵型，混合部队以「最快到最慢」的自然顺序行军，快的会先到先挨打 `[S13][S15]`。
- **Guard 命令**：让单位围绕指定目标形成防御圈，追击后会自行返回 `[S13]`。
- **单位互相穿过**：为避免寻路互撞，单位可彼此穿模 `[S14]`。

## 6. 资源系统

- **双资源 CU / RU**：中文来源明确分成两类，分别对应单位生产与科技升级 `[S10]`；社区数值表显示高阶单位同时消耗 CU 与 RU，基础单位只耗 CU `[S06]`。另有评测把 RU 描述为「更受限的科技资源」`[S14]`。
- **采集需要运输**：Salvager 把资源运回母舰或支援巡洋舰；资源点以**密集 pockets** 形式分布而非大片矿田，靠少量采集车靠近卸货点就能快速采完 `[S05]`。
- **Shipbreaking / Relics**：部分资源需要先爆破古代残骸才能取得，残骸还可能产出提供永久加成的 Relic `[S14]`；战役与多人中争夺这些目标是重要内容 `[S01][S16]`。
- **跨关持久**：战役里单位与资源带到下一关，关卡结束时不会自动收走地图上剩余资源 `[S05][S11][S14]`。
- **资源与叙事耦合**：设定上远征队在沙漠中持续消耗水等物资，所以剧情上「没时间把地图采干净」`[S05]`。

> 对 MVP 的取舍：保留 **CU/RU 双资源 + 采集车往返母舰**这个循环（它决定了「护航」和「抢资源点」的战术），砍掉 Shipbreaking、Relics 与跨关持久。

## 8. 胜利条件与多人模式

三种模式由成就列表与攻略交叉确认 `[S09][S18]`：

| 模式 | 判定 |
|---|---|
| **Carrier Annihilation** | 摧毁敌方母舰 |
| **Annihilation** | 歼灭敌方全部单位 |
| **Artifact Retrieval** | 用 Baserunner 拾取 artifact 并送到撤离区，先达到设定数量（默认 5）者胜 `[S01][S16][S17]` |

PC Gamer 对多人模式的描述最能说明原作的「双目标」结构：**一方面是保护自己的母舰（先失去母舰者判负），另一方面是争夺散落在地图上的 artifacts（先拿到 5 个者胜）**，于是形成「蹲对方撤离点 / 守 artifact 刷新点 / 用母舰抢地图控制权」三种玩法并存 `[S01]`。这一结构——**「斩首」与「占点」两条胜利线并行**——正是本项目 `Plan_Beta.md` 里「VP 点 + 斩舰即胜」的现实原型。

> 但本项目做了关键改动：**斩舰只判单局胜负，天梯按多领域加权总分排名**（用户第三轮决策）。这比原作更强调「怎么赢」而不只是「赢没赢」，也避免了「全员 rush 母舰」成为最优解。

### 阵营差异

Coalition 单位更多面，Gaalsien 更专精；最显著的差别是 **Gaalsien 可通过 Production Cruiser 在地图任意位置生产单位，而 Coalition 被绑在母舰上**，这彻底改变了双方与地图的关系 `[S01][S04]`。MVP 只做对称双方，不引入阵营差异。

## 13. 对 MVP 的直接指导（按优先级）

**P0（必须，决定「像不像卡拉克沙漠」）**

1. 程序生成的**等高线地形**，高低可辨；高地真的能带来伤害/射程优势。
2. **视线遮挡**：沙丘后面的敌人打不到，火力线用实线/虚线可视化。
3. **框选、右键移动、Shift 路径点、A 攻击移动**这套 RTS 基本操作。
4. **可移动母舰 + 生产 + 被摧毁即结束**。
5. **VP 点持续占点计分**与五级判定链结算。

**P1（强烈建议）**

6. 直射 / 曲射两种弹道，曲射可越障但有飞行时间与散布。
7. `Space` 战术视图：全图等高线 + 单位符号 + 迷雾。
8. 右键悬停时显示目标点地形优劣（蓝/橙提示的简化版）。
9. 双资源 + 采集车往返母舰。
10. 简易敌方 AI（采集、抢点、集结进攻）。
11. 结算显示八领域加权总分计分卡。

**P2（有余力）**

12. 编队（Ctrl+数字 / 数字键）、`F` 跟随、`Home` 定位母舰。
13. `replay.json` 导出、地形种子复现。
14. 烟雾/加速等技能、母舰能量过热。

## 14. 事实、推测与待核查

**已由多个独立来源交叉印证的事实**：视线约束、高地加成、母舰四子系统、框选/右键/Shift/A/Space 键位、三元克制、双胜利线、曲射越障、母舰受地形限制。

**仅单一来源支持、需保留余地**：三级地形的具体划分数 `[S15]`；Boost 精确数值 `[S04][S06]`；artifacts 默认 5 个 `[S01][S17]`；「真实物理弹道判定」的表述 `[S10]`。

**明确不采信**：D 类聚合攻略中的「两种资源叫能源点/科研点」「沙尘暴是可主动使用的战术武器」「2026 年入坑」等说法，与 A/B 类来源冲突或带有明显的自动生成痕迹 `[S20]`。

**本项目的设计判断（不是外部事实）**：连续高度场、点对称地图、VP 点、加权总分、八领域计分卡、五级判定链、10 TPS 仅作逻辑时间单位、`hello/tick/end` 三段协议——全部来自 `Plan_Beta.md`，本报告只提供原型依据，不宣称原作如此。

**待核查问题**

1. 原作高地加成的**精确公式**（是否线性、上限多少）——公开资料只有定性描述，MVP 需自定并做平衡测试。
2. 母舰坡度通行阈值的原始数值——未找到公开数据。
3. 三种胜利模式在遭遇战中的**默认权重与可配置项**——仅知可设 artifact 数量 `[S09]`。
4. 是否存在官方公开的重放 / 观战格式——本轮未检索到，MVP 的 `replay.json` 为自造格式。

## 15. 结论

卡拉克沙漠对本项目最有价值的不是「沙漠皮肤」，而是**把地形信息做成一套玩家可即时读取、AI 可精确计算的规则**：等高线既是渲染，也是移动速度、射程、伤害、视线与寻路的输入。MVP 只要把这条主链路做通（生成 → 显示 → 影响移动/开火 → 可视化反馈 → 影响胜负与计分），即使画面只是 Canvas 几何图形，操作体验也会「像」原作。

反过来，最容易跑偏的是把精力花在兵种数量、科技树或美术上——原作评测反复强调它的重心是**战术位置而非生产运营** `[S01][S11]`。MVP 因此应当刻意保持单位种类少、经济简单，把预算全部投给地形与操作反馈。
